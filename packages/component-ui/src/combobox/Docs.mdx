## Code Examples

### 基本利用（同期データ）

```tsx
import { useMemo, useState } from 'react';
import { Combobox } from '@zenkigen-inc/component-ui';

const options = [
  { value: 'apple', label: 'りんご' },
  { value: 'banana', label: 'バナナ' },
];

const MyForm = () => {
  const [value, setValue] = useState<string | null>(null);
  const [inputText, setInputText] = useState('');

  const filtered = useMemo(() => options.filter((o) => o.label.includes(inputText)), [inputText]);

  return (
    <Combobox
      value={value}
      onChange={(next, meta) => {
        setValue(next);
        setInputText(meta?.label ?? '');
      }}
      inputValue={inputText}
      onInputChange={setInputText}
      placeholder="果物を検索..."
    >
      <Combobox.Input />
      <Combobox.List>
        {filtered.map((opt) => (
          <Combobox.Item key={opt.value} value={opt.value} label={opt.label} />
        ))}
      </Combobox.List>
    </Combobox>
  );
};
```

### 非同期サジェスト

`Combobox.Loading` / `Combobox.Empty` を Compound として配置することで、ローディング表示と該当なし表示を制御します。本体に `isLoading` / `noOptionsMessage` のような prop はありません。いずれも文言は固定（Loading: `読み込み中...` / Empty: `一致する情報が見つかりません`）で、現時点では children を渡せません。

```tsx
<Combobox value={value} onChange={...} inputValue={inputText} onInputChange={setInputText}>
  <Combobox.Input />
  <Combobox.List>
    {isLoading && <Combobox.Loading />}
    {!isLoading && inputText.length > 0 && results.length === 0 && <Combobox.Empty />}
    {!isLoading && results.map((opt) => (
      <Combobox.Item key={opt.value} value={opt.value} label={opt.label} />
    ))}
  </Combobox.List>
</Combobox>
```

### 大量データの popup 抑制

未入力時は `Combobox.List` の中身を空にすることで popup を開きません。

```tsx
const filtered = useMemo(() => {
  if (inputText.length < 2) return [];
  return largeDataset.filter((item) => item.label.includes(inputText)).slice(0, 50);
}, [inputText]);

<Combobox /* ... */ listMaxHeight={240}>
  <Combobox.Input />
  <Combobox.List>
    {filtered.map((opt) => (
      <Combobox.Item key={opt.value} value={opt.value} label={opt.label} />
    ))}
  </Combobox.List>
</Combobox>;
```

`Combobox.Item` は children を省略すると `label` を 1 行 `truncate` 表示で自動レンダリングします。行の見た目を変えたい場合は次節の children を使います。

### 候補行のカスタムレイアウト（`Combobox.Item` の children）

`Combobox.Item` に children を渡すと、候補行の中身を自由にレイアウトできます（例: 名前 + 右寄せの補足テキスト）。children は**見た目のみ**で、`label` は引き続き必須です。選択時の入力値・`onChange` の `meta.label` には常に `label` が使われます。

```tsx
<Combobox.List>
  {filtered.map((fruit) => (
    <Combobox.Item key={fruit.value} value={fruit.value} label={fruit.label}>
      <span className="flex w-full min-w-0 items-center justify-between gap-4">
        <span className="truncate">{fruit.label}</span>
        <span className="typography-label12regular shrink-0">{fruit.origin}</span>
      </span>
    </Combobox.Item>
  ))}
</Combobox.List>
```

children の規約:

- **インタラクティブ要素を置かない**: 候補行は `role="option"` のため、ボタン・リンク・入力などを子孫に置けません。静的な表示要素のみにしてください
- **高さは 1 行固定**: 行の高さは `size` に応じて固定です。はみ出し対策（`truncate` / `min-w-0` / `shrink-0`）は children 側で行ってください
- **背景色を付けない**: ハイライト（背景・左ボーダー）と選択チェックは行側で描画します。children に背景色を付けると隠れてしまいます
- **文字色は行の状態に応じて継承**: 既定は `interactive02`、選択中は `interactive01`、無効（`isDisabled`）は `disabled01`、エラー時（`isError`）の選択中は `supportError` になります。補足テキストの色を children 側で固定すると、無効・エラー時も色が変わらなくなる点に注意してください
- **読み上げ**: 候補の accessible name は children のテキストの連結になります（上の例では「りんご 青森県」）。読み上げ不要な要素（装飾アイコン・区切り記号・重複情報）には、利用側で `aria-hidden` を付けてください

```tsx
<Combobox.Item value={fruit.value} label={fruit.label}>
  <span className="truncate">{fruit.label}</span>
  {/* 装飾の区切り記号は読み上げない */}
  <span aria-hidden="true">・</span>
  <span className="typography-label12regular shrink-0">{fruit.origin}</span>
</Combobox.Item>
```

### ヘルパー / エラーメッセージ

`Combobox.HelperMessage` / `Combobox.ErrorMessage` は **`Combobox.Input` の direct children** に配置します（TextInput の aria-describedby 連携を使うため）。

```tsx
<Combobox /* ... */ isError={hasError}>
  <Combobox.Input>
    <Combobox.HelperMessage>選択中: {value ?? '未選択'}</Combobox.HelperMessage>
    <Combobox.ErrorMessage>入力内容にエラーがあります</Combobox.ErrorMessage>
  </Combobox.Input>
  <Combobox.List>{/* ... */}</Combobox.List>
</Combobox>
```

### 入力欄に名前を付ける

placeholder だけでは入力欄の accessible name になりません。`Combobox.Input` の `id`（`<label htmlFor>` と関連付け）/ `aria-label` / `aria-labelledby` のいずれかで名前を付けてください。単一選択・複数選択のどちらでも使えます。

```tsx
<label htmlFor="favorite-fruit">好きな果物</label>
<Combobox /* ... */>
  <Combobox.Input id="favorite-fruit" />
  <Combobox.List>{/* ... */}</Combobox.List>
</Combobox>

{/* 画面上にラベルが無い場合 */}
<Combobox /* ... */>
  <Combobox.Input aria-label="好きな果物" />
  <Combobox.List>{/* ... */}</Combobox.List>
</Combobox>
```

### 複数選択（チップ）

`isMultiple` を指定すると複数選択モードになり、`value` は ID の配列（`string[]`）、`onChange` は「次の配列」と差分（`{ type: 'add' | 'remove', value }`）を受け取ります。選択済みの値は、利用側が `Combobox.Chip` を `Combobox.Input` の children に並べて表示します。

```tsx
const [selectedIds, setSelectedIds] = useState<string[]>([]);
const [inputText, setInputText] = useState('');

// チップ表示用（state ではなく value からの導出）。value の順に並べる
const selectedFruits = selectedIds.flatMap((id) => {
  const fruit = fruits.find((item) => item.value === id);
  return fruit != null ? [fruit] : [];
});
// 候補: 選択済みを除外し、入力で絞り込む（利用側の責務）
const candidates = fruits.filter((fruit) => !selectedIds.includes(fruit.value) && fruit.label.includes(inputText));

<Combobox
  isMultiple
  value={selectedIds}
  onChange={(next) => setSelectedIds(next)}
  inputValue={inputText}
  onInputChange={setInputText}
  placeholder="果物を検索..."
>
  <Combobox.Input aria-label="果物">
    {selectedFruits.map((fruit) => (
      <Combobox.Chip key={fruit.value} value={fruit.value} label={fruit.label} />
    ))}
  </Combobox.Input>
  <Combobox.List>
    {candidates.map((fruit) => (
      <Combobox.Item key={fruit.value} value={fruit.value} label={fruit.label} />
    ))}
  </Combobox.List>
</Combobox>;
```

ふるまい:

- 候補を選ぶ（クリック / `Enter`）とチップが追加され、入力が空に戻ります。**候補リストは閉じません**。選択済みの候補を選ぶと選択を解除します
- 削除はチップの ✗（クリック、または `Shift + Tab` で ✗ に移動して `Enter` / `Space`）と、入力が空のときの `Backspace`（`value` の末尾を削除）で行います
- 入力欄の文字は常に未確定の検索語です。blur・`Escape`・✗ へのフォーカス移動で空に戻り、`value` は変わりません
- 選択がある間は placeholder を表示しません。クリアボタンはありません（`onClickClearButton` は指定できません）
- 追加・削除は `aria-live` で読み上げます（チップの `label` を使用）

チップの規約:

- **`value` の全要素について、`value` と同じ順にチップを並べてください**。`Backspace` は描画順ではなく `value` の末尾を削除します。`value` にあってチップを描画していない値も、見えないだけで選択中として扱われます
- 1 つの `value` につきチップは 1 つにしてください
- チップは `Combobox.Input` の **直接の子** に置いてください（Fragment やラッパーコンポーネントで包むと認識されません）
- 色は `gray` 固定で、`size="large"` でもチップは `medium` のままです。単一選択モードでは描画されません
- 長いラベルは 1 行で末尾を「…」で省略します（チップの最大幅は入力欄の中のチップ領域の幅）。✗ は常に表示され、全文は `title`（マウスオーバー）とスクリーンリーダーで伝わります

追加・削除に応じた副作用（API 呼び出し等）は `onChange` の第 2 引数で受け取れます。

```tsx
const handleChange = (next: string[], meta: ComboboxMultipleChangeMeta) => {
  setSelectedIds(next);
  if (meta.type === 'add') {
    attachTag(meta.value);
  } else {
    detachTag(meta.value);
  }
};
```

### 作成行（`Combobox.CreateItem`）

候補に無い名前を新しく作って選べるようにするには、`Combobox.List` に `Combobox.CreateItem` を置きます。入力に応じて末尾に「「{入力文字}」を作成」行が表示され、Enter / クリックで `onCreate(text)` が呼ばれます（`text` は入力を trim したもの）。

```tsx
const [fruits, setFruits] = useState<Fruit[]>(initialFruits); // マスタ（作成で増える）
const [selectedIds, setSelectedIds] = useState<string[]>([]);
const [inputText, setInputText] = useState('');

const handleCreate = (text: string) => {
  const created = { value: crypto.randomUUID(), label: text }; // 実際は API で作成
  setFruits((prev) => [...prev, created]);
  setSelectedIds((prev) => [...prev, created.value]);
  setInputText(''); // 作成に成功したら利用側で入力を空にする
};

<Combobox
  isMultiple
  value={selectedIds}
  onChange={(next) => setSelectedIds(next)}
  inputValue={inputText}
  onInputChange={setInputText}
>
  <Combobox.Input aria-label="果物">
    {selectedFruits.map((fruit) => (
      <Combobox.Chip key={fruit.value} value={fruit.value} label={fruit.label} />
    ))}
  </Combobox.Input>
  <Combobox.List>
    {candidates.length === 0 && <Combobox.Empty />}
    {candidates.map((fruit) => (
      <Combobox.Item key={fruit.value} value={fruit.value} label={fruit.label} />
    ))}
    <Combobox.CreateItem onCreate={handleCreate} />
  </Combobox.List>
</Combobox>;
```

- **表示するかどうかはライブラリが判定します。利用側は置くだけです**。入力が空（空白のみを含む）・IME 変換中・`Combobox.Loading` の描画中・既存と重複しているときは、区切り線も含めて何も表示しません
- 重複の既定の判定は「候補の `Combobox.Item` の `label`、または選択中のチップの `label` と完全一致（`===`）」です。選択済みを候補から除外していても、チップの `label` と一致すれば作成行は出ません
- 大文字小文字・全角半角・かなを同一視したい場合や、画面に出ていない既存データと照合したい場合は `checkDuplicate`（同期関数。`true` で作成行を出さない）を渡します。指定すると既定の判定を**置き換えます**（候補との一致も含めて利用側で判定してください）
- `onCreate` の後、ライブラリは `onChange` も `onInputChange` も呼びません。`value` への追加と、**成功時の入力のクリアは利用側で行います**。入力をクリアしなくても、追加したチップの `label` と一致するため作成行は消えます（既定の判定の場合）
- 複数選択では作成後も候補リストは開いたままです
- 候補が 0 件のときは `Combobox.Empty` と作成行を並べて表示でき、作成行が active になります
- 文言（「「{入力文字}」を作成」）は固定です。`Combobox.CreateItem` は `Combobox.List` の **直接の子** として 1 つだけ置いてください（2 つ目以降や、Fragment・ラッパーコンポーネントで包んだものは何も表示されず、`onCreate` も呼ばれません）
- 重複の最終的な防止はサーバー側の検証で行ってください

作成 API が非同期の場合は、**作成中に `Combobox.Loading` を描画して二重作成を防ぎ**、失敗時は入力を残して再試行できるようにします。

```tsx
const [isCreating, setIsCreating] = useState(false);

const handleCreate = async (text: string) => {
  setIsCreating(true); // Loading の描画中は作成行が出ないため、連打しても二重に作成されない
  try {
    const created = await createFruit(text);
    setSelectedCache((prev) => new Map(prev).set(created.value, created));
    setSelectedIds((prev) => [...prev, created.value]);
    setInputText(''); // 成功時のみクリアする
  } catch {
    setErrorMessage(`「${text}」を作成できませんでした`); // 入力は残るので、そのまま再試行できる
  } finally {
    setIsCreating(false);
  }
};

<Combobox.List>
  {isCreating && <Combobox.Loading />}
  {/* ... */}
  <Combobox.CreateItem onCreate={handleCreate} />
</Combobox.List>;
```

### 複数選択の非同期検索

候補をサーバーで検索する場合は、検索語が変わると選択済みの表示情報が検索結果から消えるため、追加時に保持しておきます。作成行には、画面に出ていない既存データとの重複をライブラリが検出できないため `checkDuplicate` を渡し、**選択済みを除外する前の検索結果**で判定します（Story: `MultipleAsyncSearch`）。

```tsx
const [selectedIds, setSelectedIds] = useState<string[]>([]);
const [selectedCache, setSelectedCache] = useState<Map<string, Fruit>>(new Map());
const { data: results = [], isLoading } = useFruitSearch(inputText); // 利用側の検索フック
// isCreating / handleCreate は「作成行（Combobox.CreateItem）」節の非同期版と同じ定義を使う

const handleChange = (next: string[], meta: ComboboxMultipleChangeMeta) => {
  if (meta.type === 'add') {
    const fruit = results.find((result) => result.value === meta.value);
    if (fruit != null) {
      setSelectedCache((prev) => new Map(prev).set(fruit.value, fruit));
    }
  }
  setSelectedIds(next);
};

const selectedFruits = selectedIds.flatMap((id) => {
  const fruit = selectedCache.get(id);
  return fruit != null ? [fruit] : [];
});

<Combobox isMultiple value={selectedIds} onChange={handleChange} inputValue={inputText} onInputChange={setInputText}>
  <Combobox.Input aria-label="果物">
    {selectedFruits.map((fruit) => (
      <Combobox.Chip key={fruit.value} value={fruit.value} label={fruit.label} />
    ))}
  </Combobox.Input>
  <Combobox.List>
    {(isLoading || isCreating) && <Combobox.Loading />}
    {!isLoading &&
      results
        .filter((fruit) => !selectedIds.includes(fruit.value)) // 選択済みは候補から除外（再検索で戻ってくるため）
        .map((fruit) => <Combobox.Item key={fruit.value} value={fruit.value} label={fruit.label} />)}
    <Combobox.CreateItem
      onCreate={handleCreate}
      checkDuplicate={(text) => results.some((fruit) => fruit.label === text)}
    />
  </Combobox.List>
</Combobox>;
```

- 検索中は `Combobox.Loading` を描画してください。Loading の描画中は作成行が出ないため、古い検索結果で一瞬「作成」が出ることを防げます
- 初期値（編集画面など）がある場合は、初期表示時に選択済みの値の表示情報を取得してキャッシュに入れてください

### 外せないチップ

最初から設定されていて外せない値は、そのチップに `isRemovable={false}` を指定します。✗ が表示されず、`Backspace`・候補の再選択でも外れません。外せるかどうかは**描画中のチップの宣言だけ**で判定するため、外せない値のチップは必ず描画してください。

```tsx
<Combobox.Input aria-label="果物">
  {selectedFruits.map((fruit) => (
    <Combobox.Chip
      key={fruit.value}
      value={fruit.value}
      label={fruit.label}
      isRemovable={!fixedIds.includes(fruit.value)}
    />
  ))}
</Combobox.Input>
```

`Combobox.Item` の children（候補行のカスタムレイアウト）は複数選択でも同じように使えます（Story: `MultipleWithCustomItem`）。
